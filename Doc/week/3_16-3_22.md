五、用户问题专项支持（海外团队）

针对外部团队反馈的 连接 / 预览 / 拍照异常问题，完成统一分析与解决：
问题现象
- 拍照超时（408 timeout）
- 预览白屏 / 绿屏
- 预览卡死
- 连接失败（network lost / timeout）
问题分析
- 部分问题与 固件版本较低（v1.1.22） 相关
- 使用 OSC 协议 存在一定不稳定性
- “Bluetooth Wakeup” 能缓解问题，说明连接链路存在状态同步问题
解决与建议
- 建议升级至 最新固件版本
- 推荐优先使用 SDK 方式替代 OSC 调用
- 明确 Wi-Fi 为主链路，Bluetooth 仅用于辅助唤醒与状态同步
