    - **验证(全程 headless,无需显示器)**：输出 `h264/640x360/239帧`(与输入一致)、`315KB→160KB`(约一半)、`ffmpeg -f null` 完整解码零报错、抽首帧是正确的 640x360 彩条。
    - 配套讲解文档 `9_Simplest_Transcoder/逐步讲解.md`(同播放器结构,T1~T4 四节 + 镜像对照 + 速查表)。

## 跨机器同步规则

**核心约定**：本文件是 ffmpeg 学习的 single source of truth。每次推进**任何一项**学习活动后立即更新它。

**典型推进动作（任一发生都要更新）**：

- 读完 / 重读完某一份文档
- 写了 / 改了 / 调通了任何代码
- 撞坑 + 解决坑（必须记录踩坑笔记）
- 完成自检题（哪几道答上了、哪几道还不熟）
- 跨了一个学习阶段（阶段 1 → 阶段 2 → 阶段 3）
- 新增 / 改写文档

**更新内容**（每次至少改动）：

1. "最近完成的动作"区块末尾加新条目（带日期）
2. "下一步待办"里把已完成项打 ✅，或调整优先级
3. 如果有新文档 / 新代码产出，更新"已完成成果清单"

**同步流程**：

```bash
# 推进完任何一项后:
git add Doc/ffmpeg/99-学习进度.md  # (以及新增/修改的文档/代码)
git commit -m "ffmpeg: <描述这次推进>"
git push

# 切到别的电脑:
git pull
# 然后用顶部的"一句话恢复指令"启动新会话
```
