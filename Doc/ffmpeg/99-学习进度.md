14. ✅ **最简播放器 `project/8_Simplest_Player/` 推进到第⑤步**（一步一提交，每步带教学注释 + 链回对应文档章节）：
    - **第①步 demux**：CMake 接 ffmpeg+SDL2（pkg-config）、`avformat_open_input` 打开文件
    - **第②步**：`avformat_find_stream_info` + `av_find_best_stream` 找视频流，读宽高/编码（codecpar 只是"描述"）
    - **第③步 建解码器**：`avcodec_find_decoder`（无状态算法本体）→ `alloc_context3` → `parameters_to_context` 拷参 → `avcodec_open2`，对应 01 §4 初始化三步
    - **第④步 解码循环**：外层 `av_read_frame` 读包只喂视频流、内层 `avcodec_receive_frame` 把攒着的帧取干净（处理 EAGAIN/EOF）、末尾喂 NULL 包 drain 残余帧。打印首帧 `format=yuv420p`（不是 RGB！）+ linesize + pts。**帧数 239 与 ffprobe 核对一致**
    - **第⑤步 YUV→RGB**：懒创建 `SwsContext`（拿到首帧按真实宽高/格式建）+ `av_image_alloc` 目标 RGB24 + `sws_scale`。首帧落盘 PPM 做无窗口验证——彩条画面正常、颜色正确、无斜切（**关键坑：PPM 必须按 `rgbLinesize[0]` stride 逐行写，不能一把 fwrite，否则行尾填充会把图斜切**）
    - **踩坑记录**：(a) `av_get_pix_fmt_name` 在 `libavutil/pixdesc.h`，漏 include 会误报成 `av_get_sample_fmt_name`；(b) swscale 提示 `No accelerated colorspace conversion from yuv420p to rgb24` 是 benign——只是该组合无 SIMD 路径退回 C 实现，不影响正确性；(c) 本例 1280 宽，linesize 恰好 = width 无填充，但代码仍严格按 linesize 走（换非对齐宽度才不会踩坑）
    - **收获**：send/receive 是解耦的两条管道（喂一个包可能 0 帧或多帧）、解码器吐 YUV 不是 RGB、linesize ≠ width 这三点从"读过"变"手写过"

15. ✅ **最简播放器 ⑥⑦ 完成——端到端流水线打通**：
    - **第⑥步 SDL 显示**：`SDL_Init` 只初始化子系统，窗口/渲染器/纹理懒创建（首帧按真实尺寸，和⑤的 sws 同一套路）。纹理用 `SDL_PIXELFORMAT_RGB24` 对上⑤输出；每帧 `SDL_UpdateTexture`（行字节数仍传 `rgbLinesize[0]`，**linesize 坑在④⑤⑥反复出现**）+ `RenderClear/Copy/Present`；`SDL_PollEvent` 处理 `SDL_QUIT`（不处理窗口会"无响应"）。删掉⑤的 PPM 调试导出。
    - **第⑦步 pts 节奏控制**：`时间(秒) = pts × av_q2d(videoStream->time_base)`。记第一帧 `SDL_GetTicks` 为时间原点，每帧算 `targetMs` 与 `elapsedMs` 比对，超前则 `SDL_Delay` 补齐；判 `AV_NOPTS_VALUE`。
    - **已知局限（有意省略，留给加音频时补）**：只"等快的"不"追慢的"——没有丢帧逻辑，某帧解码/转换慢就会略拖后。实测 8.02s 视频墙钟约 9.5s 走完（纯 C swscale 偏慢）。真同步是音视频同步（主时钟换音频），见 04 §同步。
    - **验证**：`SDL_VIDEODRIVER=dummy` 无窗口冒烟测试，整条链路跑通、239 帧、节奏生效、无崩溃；去掉 `SDL_Delay` 则零点几秒刷完，反证节奏控制有效。**真窗口画面待本机带显示器确认。**

## 跨机器同步规则

**核心约定**：本文件是 ffmpeg 学习的 single source of truth。每次推进**任何一项**学习活动后立即更新它。

**典型推进动作（任一发生都要更新）**：

- 读完 / 重读完某一份文档
- 写了 / 改了 / 调通了任何代码
- 撞坑 + 解决坑（必须记录踩坑笔记）
- 完成自检题（哪几道答上了、哪几道还不熟）
- 跨了一个学习阶段（阶段 1 → 阶段 2 → 阶段 3）
- 新增 / 改写文档

**更新内容**（每次至少改动）：

1. "最近完成的动作"区块末尾加新条目（带日期）
2. "下一步待办"里把已完成项打 ✅，或调整优先级
3. 如果有新文档 / 新代码产出，更新"已完成成果清单"

**同步流程**：

```bash
# 推进完任何一项后:
git add Doc/ffmpeg/99-学习进度.md  # (以及新增/修改的文档/代码)
git commit -m "ffmpeg: <描述这次推进>"
git push

# 切到别的电脑:
git pull
# 然后用顶部的"一句话恢复指令"启动新会话
```
