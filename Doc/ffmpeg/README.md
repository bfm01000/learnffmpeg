## 一、面试复习路径（先看这里）

### 1. 30 分钟快速建立地图

先读两遍 [00-FFmpeg全景导读.md](./00-FFmpeg全景导读.md)，脑子里要能画出这条主线：

```text
文件/网络流
  -> 解封装 libavformat
  -> AVPacket
  -> 解码 libavcodec
  -> AVFrame
  -> swscale / swresample / filter / 硬件帧处理
  -> 渲染 / 播放 / 编码 / 封装 / 推流

时间戳、引用计数、像素/采样格式贯穿全程
```

面试时绝大多数问题，都可以放回这条链路里回答：数据在哪里、格式是什么、时间戳怎么算、是否发生拷贝、上下游协议/容器/编码是否匹配。

### 3. 高频主线 12 题

这些题要能脱稿回答，回答时尽量带“工程现象 + 根因 + 解决方案”：

1. `AVPacket` 和 `AVFrame` 的区别？生命周期怎么管理？
2. `send_packet / receive_frame` 为什么都要循环处理 `EAGAIN`？
3. `PTS / DTS / time_base` 分别是什么？为什么 B 帧会导致 DTS 和 PTS 不同？
4. `linesize` 为什么不等于 `width * bytes_per_pixel`？
5. `YUV420P / NV12 / NV21 / RGB24` 怎么区分？花屏、绿屏、红蓝反色怎么排查？
6. `FLTP / S16 / planar / packed` 怎么区分？AAC 解码后为什么不能直接送声卡？
7. H.264 为什么能压缩？I/P/B、GOP、IDR、SPS/PPS 怎么讲清楚？
8. MP4 里的 H.264 和 Annex-B 裸流有什么区别？什么时候需要 bitstream filter？
9. `CRF / CBR / VBR / VBV / GOP / B 帧 / zerolatency` 怎么选？
10. RTMP / HLS / HTTP-FLV / RTP / WebRTC 的延迟、传输层和适用场景怎么对比？
11. 音视频同步怎么做？为什么播放器常以音频时钟为主？
12. 硬解码帧为什么不能直接喂 `sws_scale`？零拷贝链路怎么设计？

## 四、当前缺口与建议补充

现有文档已经覆盖面试核心区，但如果目标是中高级 C++ 音视频工程师，后续建议补三类内容：

1. **可运行工程代码**：最简播放器、最简转码器、MP4 转 Annex-B、RTMP 推流、音频重采样播放。
2. **avfilter 专题**：滤镜图构建、时间戳传递、硬件滤镜和软件滤镜混用。
3. **项目复盘模板**：把一次花屏、一次不同步、一次首屏慢、一次硬编兼容性问题整理成 STAR + 技术链路回答。
