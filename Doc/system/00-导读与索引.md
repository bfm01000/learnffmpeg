## 一、为什么这样排序（JD 驱动）

把目标 JD 拆开看，它反复强调、权重最高的是两件事：**理解 Linux 内存管理机制** 和 **理解多进程管理机制**（在任职资格第 5、6 条各出现一次，等于强调了两遍）。其次是多线程/共享内存/网络通讯应用编程、多核架构多任务、MQTT/HTTPS/WebRTC/TCP 协议、gcc/cmake/gdb 工具链；驱动与内核是"优先"的加分项。

所以本库把 **进程（02）** 和 **内存（03）** 放在最前，紧接 **文件 IO/epoll（06）**、**IPC（05）**、**线程/调度（04）**、**网络编程（07）** 这些"直接面对操作系统"的核心，再到 **协议原理（08）**、**多核（09）**、**工具链（10）**，最后是加分项 **驱动/内核（11）**。

> **和你已有知识库的分工**：C++ 语言层面（同步原语语义、原子/内存序、智能指针、内存池）在 **cpp 库**；音视频协议与编解码（RTP/RTMP/H264/FFmpeg）在 **ffmpeg 库**。本库聚焦 **Linux 系统层**：进程、虚拟内存、IPC、系统调用、网络编程、调试工具——也就是从"会调库"跨到"懂系统"的那一层。

## 四、推荐学习路线（按优先级，不是编号）

1. **建立地图**：先读 [[01-Linux系统编程全景导读]]，搞清 JD 要什么、自己在哪、先补什么。
2. **打底（直接面对 OS 的核心）**：[[02-进程管理与多进程编程]] → [[03-Linux内存管理机制]] → [[06-文件IO与IO多路复用]]——JD 反复强调、面试基本盘，讲到能白板画图。
3. **攻坚（通信与并发）**：[[05-进程间通信IPC]] → [[04-多线程与Linux调度]] → [[07-Linux网络编程]]——共享内存传帧、epoll server 跑通；并发部分与 cpp 库 01~04 交叉印证。
4. **协议与多核（JD 点名）**：[[08-网络协议原理]] → [[09-多核架构与缓存一致性]]——讲清每个协议解决什么、用在哪。
5. **工具与加分**：[[10-工具链与调试]]（日常必备）→ [[11-Linux驱动与内核基础]]（加分项，了解为主）。
6. **自测**：用 [[99-自测题与面试标准答案]] 盖住答案检验是否真能"讲出来"。

> **不要做**：不要一上来啃内核源码、写完整驱动。对这个岗位，应用层系统编程 + 调试能力的性价比远高于内核深挖；驱动按"听得懂、能聊"准备即可。
