## 一、为什么这样排序

音视频高级岗的区分点不在“会不会写 C++”，而在**并发**与**资源管理**——解码/渲染/音频多线程流水线、零拷贝传帧、FFmpeg 裸资源的生命周期管理。因此本库把**并发（01–04、24）**和**内存/资源（05–07、15、16、21、22）**放在最前，其后是 OOP 对象模型、泛型与编译期（14、17）、现代特性、容器与关键字，以及 C/C++ 互操作（23）。

> “高级”相对“中级”多考的，是 **14 模板/泛型、15 RVO 与三/五/零法则、16 异常安全、17 C++20/协程** 这几块——通过 14–17 补齐。而 **21 内存对齐/SIMD/缓冲、22 自定义分配器/内存池、23 C 互操作/FFmpeg 资源封装、24 线程池/流水线架构** 则是把通用 C++ 能力落到音视频垂直场景的专项深挖，是这一岗位真正的「深水区」。设计模式、零拷贝/硬件编解码由本仓库的 `设计模式/`、`零拷贝/` 目录覆盖，不在本目录重复。

## 四、推荐学习路线

1. **打底**（资源管理）：05 → 06 → 07 → **15** ——RAII / 智能指针 / 移动语义 / RVO 与三五零法则，建立完整的资源与对象生命周期观。
2. **攻坚**（并发）：01 → 02 → 03 → 04 ——音视频岗最该投入精力的一块，02 的内存序务必吃透。
3. **巩固**（OOP）：08 ——对象模型与虚表，配合 11 的 `dynamic_cast`。
4. **进阶**（高级岗加分）：**14**（模板/泛型）→ **16**（异常安全）→ **17**（C++20 与协程）——这三块是从“中级”跨到“高级”的关键。
5. **音视频专项深水区**（本岗位真正的区分点）：**21**（对齐/SIMD/缓冲）→ **22**（分配器/内存池）→ **23**（C 互操作/FFmpeg 资源封装）→ **24**（线程池/流水线架构）——把通用 C++ 能力落到解码/渲染/音频流水线的实战场景，建议在打底+攻坚之后学，能把 01–07 的知识串成系统。
6. **补全**（特性与工具）：09 → 10 → 12 → 11 → 13。
7. **选学**（⭐非必须，有余力再看）：18（编译链接）、19（STL 算法与迭代器）、20（const 正确性与编译期计算）。
