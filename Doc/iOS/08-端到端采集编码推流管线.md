## 一、全景导读：一条完整的管线

### 1.1 数据流全景

```
┌─────────────────────────────────────────────────────────────────────┐
│                        iOS 直播推流完整管线                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  [1] 摄像头 ISP                                                      │
│       │                                                              │
│       ▼ NV12 CVPixelBuffer (IOSurface)                               │
│  [2] AVCaptureVideoDataOutput 回调 (串行队列)                        │
│       │                                                              │
│       ├────────────────────────────────────────────┐                │
│       ▼                                            ▼                │
│  [3a] 预览路线 (Metal)                     [3b] 编码路线              │
│  CVMetalTextureCache                     VTCompressionSession       │
│  NV12→2×MTLTexture                       EncodeFrame(pixelBuffer)   │
│       │                                            │                │
│       ▼                                            ▼                │
│  [4a] Metal Shader                       [4b] 编码回调               │
│  YUV→RGB                                CMSampleBuffer(AVCC)        │
│  MTKView.currentDrawable                       │                    │
│       │                                         ▼                   │
│       ▼                                  [5] AVCC→Annex-B 转换      │
│  [5a] 上屏                               补 SPS/PPS + 起始码替换    │
│                                                │                    │
│                                                ▼                   │
│                                         [6] 推流层 (C++)            │
│                                         RTMP/WebRTC 封包 & 发送     │
│                                                                      │
│  ★ 预览线和编码线共享同一个 CVPixelBuffer (IOSurface) — 零拷贝!      │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.2 核心架构设计原则

1. **零拷贝**：摄像头出的 CVPixelBuffer(IOSurface) 同时喂给预览(Metal)和编码(VT)，不经过 CPU
2. **异步流水线**：采集→编码→推流各自独立线程，靠队列解耦
3. **背压控制**：编码跟不上采集时主动丢帧，而不是无限积压
4. **平台桥接**：OC 层负责采集+编解码+渲染，C++ 引擎负责网络/协议/音画同步

### 2.2 面试标准回答（综合题）

#### Q：你给我们完整讲讲 iOS 端从摄像头打开到画面推出去的整个链路吧

**面试官想听什么：** 你能不能把前面所有知识点串成一条完整的、有逻辑的链路。

**🗣️ 标准回答（可背诵）：**

> "我按数据流向来讲，分四段。第一段是采集——用 AVCaptureSession 配置后置摄像头，加 AVCaptureVideoDataOutput 拿到 NV12 的 CVPixelBuffer。输出回调设在一个串行队列上，回调里不能阻塞——拿到 buffer 后立即 retain 并 dispatch 到处理线程。这里的关键设计决策是 output 的 pixel format 必须设为摄像头的原生 NV12 格式，才能保证后面的零拷贝链路不断。
>
> 第二段是并行处理——同一个 CVPixelBuffer 分两路。预览路线走 CVMetalTextureCache 把 NV12 的两个平面映射成两张 Metal 纹理（Y=R8、UV=RG8），在 Metal shader 里做 YUV→RGB 渲染到 MTKView，全程零拷贝，数据不下 CPU。编码路线把同一个 CVPixelBuffer 连同 PTS 喂给 VTCompressionSession——设置了 RealTime=true 和 AllowFrameReordering=false 这两个低延迟旋钮。编码是异步的，结果在回调里拿 CMSampleBuffer。
>
> 第三段是比特流处理——编码回调里拿到的是 AVCC 格式（4 字节长度前缀），而且 SPS/PPS 不在数据流里，单独存在 CMVideoFormatDescription 里。推 RTMP 前必须做两件事：用 CMVideoFormatDescriptionGetH264ParameterSetAtIndex 取出 SPS/PPS，在每个 IDR 前注入；把所有 NALU 的长度前缀替换成 00 00 00 01 起始码。这个和 Android 端正好相反——MediaCodec 本来就是 Annex-B。
>
> 第四段是推流——转换后的 Annex-B 数据进入我们的 C++ 推流引擎，封装成 FLV tag，通过 RTMP 发出去。C++ 引擎也负责音视频同步——以音频时钟为基准，视频帧按 PTS 对齐。整个管线是异步流水线架构，各环节通过队列解耦，背压控制靠采集侧的 alwaysDiscardsLateVideoFrames 属性自动丢帧。
>
> 您可以深入了解任何一个环节——采集配置、编码参数、Metal 零拷贝、或者格式转换的字节级细节。"

### 3.2 RTMPBroadcaster.m（核心管线实现）

```objc
//  RTMPBroadcaster.m
//  完整的采集→编码→推流管线实现

#import "RTMPBroadcaster.h"
#import "H264FormatConverter.h"  // AVCC → Annex-B 转换

// ============================================================
// MARK: - RTMPBroadcasterConfig
// ============================================================
@implementation RTMPBroadcasterConfig
- (instancetype)init {
    self = [super init];
    if (self) {
        _videoWidth    = 720;
        _videoHeight   = 1280;
        _videoFPS      = 30;
        _videoBitrate  = 1500000;
        _audioSampleRate = 48000;
        _audioBitrate  = 96000;
        _cameraPosition = AVCaptureDevicePositionFront;
        _rtmpURL       = @"";
    }
    return self;
}
@end

// ============================================================
// MARK: - RTMPBroadcaster
// ============================================================
@implementation RTMPBroadcaster {
    RTMPBroadcasterConfig *_config;

    // ---- 采集 ----
    AVCaptureSession          *_captureSession;
    AVCaptureDevice           *_currentCamera;
    AVCaptureDeviceInput      *_videoInput;
    AVCaptureVideoDataOutput  *_videoOutput;
    dispatch_queue_t           _captureQueue;

    // ---- 预览 (Metal 零拷贝渲染) ----
    MTKView                   *_previewView;
    id<MTLDevice>             _metalDevice;
    id<MTLCommandQueue>       _metalCommandQueue;
    CVMetalTextureCacheRef    _textureCache;
    id<MTLRenderPipelineState> _pipelineState;  // 简化版，完整见 Metal 渲染文档

    // ---- 编码 ----
    VTCompressionSessionRef    _encoderSession;
    dispatch_queue_t           _encodeQueue;

    // ---- 音频 ----
    AudioUnit                  _audioUnit;

    // ---- 推流 ----
    dispatch_queue_t           _streamQueue;

    // ---- 状态 ----
    BOOL                       _isBroadcasting;
    int                        _frameCount;
    BOOL                       _forceKeyFrame;
    BOOL                       _muted;
}

// ============================================================
// MARK: - 初始化
// ============================================================
- (instancetype)initWithConfig:(RTMPBroadcasterConfig *)config {
    self = [super init];
    if (!self) return nil;

    _config = config;

    // 创建各级队列
    _captureQueue = dispatch_queue_create("com.rtmp.capture", DISPATCH_QUEUE_SERIAL);
    _encodeQueue  = dispatch_queue_create("com.rtmp.encode",  DISPATCH_QUEUE_SERIAL);
    _streamQueue  = dispatch_queue_create("com.rtmp.stream",  DISPATCH_QUEUE_SERIAL);

    // Metal 初始化
    _metalDevice = MTLCreateSystemDefaultDevice();
    _metalCommandQueue = [_metalDevice newCommandQueue];

    // 创建预览视图
    _previewView = [[MTKView alloc] initWithFrame:CGRectZero device:_metalDevice];
    _previewView.colorPixelFormat = MTLPixelFormatBGRA8Unorm;
    _previewView.framebufferOnly = NO;

    // 创建零拷贝纹理缓存
    CVMetalTextureCacheCreate(kCFAllocatorDefault, NULL, _metalDevice, NULL, &_textureCache);

    return self;
}

- (void)dealloc {
    [self stopBroadcasting];
    if (_textureCache) {
        CVMetalTextureCacheFlush(_textureCache, kCVOptionFlags_None);
        CFRelease(_textureCache);
    }
}

// ============================================================
// MARK: - 第一段: 采集管线搭建
// ============================================================
- (void)setupCapture {
    _captureSession = [[AVCaptureSession alloc] init];
    _captureSession.sessionPreset = AVCaptureSessionPreset1280x720;

    // --- 视频输入 ---
    _currentCamera = [self findCamera:_config.cameraPosition];
    if (!_currentCamera) {
        NSLog(@"❌ 摄像头不可用");
        return;
    }

    _videoInput = [AVCaptureDeviceInput deviceInputWithDevice:_currentCamera error:nil];
    if ([_captureSession canAddInput:_videoInput]) {
        [_captureSession addInput:_videoInput];
    }

    // --- 视频输出 ---
    _videoOutput = [[AVCaptureVideoDataOutput alloc] init];
    _videoOutput.videoSettings = @{
        (id)kCVPixelBufferPixelFormatTypeKey:
            @(kCVPixelFormatType_420YpCbCr8BiPlanarFullRange) // ★ 原生 NV12
    };
    _videoOutput.alwaysDiscardsLateVideoFrames = YES; // ★ 实时丢帧策略
    [_videoOutput setSampleBufferDelegate:self queue:_captureQueue];

    if ([_captureSession canAddOutput:_videoOutput]) {
        [_captureSession addOutput:_videoOutput];
    }
}

- (AVCaptureDevice *)findCamera:(AVCaptureDevicePosition)position {
    AVCaptureDeviceDiscoverySession *discovery =
        [AVCaptureDeviceDiscoverySession
            discoverySessionWithDeviceTypes:@[AVCaptureDeviceTypeBuiltInWideAngleCamera]
                                  mediaType:AVMediaTypeVideo
                                   position:position];
    return discovery.devices.firstObject;
}

// ============================================================
// MARK: - 第二段: 编码器搭建
// ============================================================
- (void)setupVideoEncoder {
    VTCompressionSessionCreate(
        kCFAllocatorDefault,
        _config.videoWidth, _config.videoHeight,
        kCMVideoCodecType_H264,
        NULL, NULL, NULL,
        &EncoderOutputCallback,     // ★ 编码回调
        (__bridge void *)self,
        &_encoderSession
    );

    // 低延迟实时编码配置
    VTSessionSetProperty(_encoderSession,
        kVTCompressionPropertyKey_RealTime, kCFBooleanTrue);
    VTSessionSetProperty(_encoderSession,
        kVTCompressionPropertyKey_AllowFrameReordering, kCFBooleanFalse);

    int bitrate = _config.videoBitrate;
    CFNumberRef br = CFNumberCreate(NULL, kCFNumberIntType, &bitrate);
    VTSessionSetProperty(_encoderSession,
        kVTCompressionPropertyKey_AverageBitRate, br);
    CFRelease(br);

    int fps = _config.videoFPS;
    CFNumberRef fpsNum = CFNumberCreate(NULL, kCFNumberIntType, &fps);
    VTSessionSetProperty(_encoderSession,
        kVTCompressionPropertyKey_ExpectedFrameRate, fpsNum);
    CFRelease(fpsNum);

    int gop = _config.videoFPS * 2; // 2 秒 GOP
    CFNumberRef gopNum = CFNumberCreate(NULL, kCFNumberIntType, &gop);
    VTSessionSetProperty(_encoderSession,
        kVTCompressionPropertyKey_MaxKeyFrameInterval, gopNum);
    CFRelease(gopNum);

    VTSessionSetProperty(_encoderSession,
        kVTCompressionPropertyKey_ProfileLevel,
        kVTProfileLevel_H264_Baseline_AutoLevel);

    VTCompressionSessionPrepareToEncodeFrames(_encoderSession);
}

// ============================================================
// MARK: - 第三段: 采集回调（数据入口）
// ============================================================
- (void)captureOutput:(AVCaptureOutput *)output
didOutputSampleBuffer:(CMSampleBufferRef)sampleBuffer
       fromConnection:(AVCaptureConnection *)connection {

    CVPixelBufferRef pixelBuffer = CMSampleBufferGetImageBuffer(sampleBuffer);
    if (!pixelBuffer) return;

    CMTime pts = CMSampleBufferGetPresentationTimeStamp(sampleBuffer);

    // ★ 并行分发：retain 一次，预览和编码各 release 一次
    CVPixelBufferRetain(pixelBuffer); // 给编码路线
    CVPixelBufferRetain(pixelBuffer); // 给预览路线

    // ---- 预览路线: Metal 渲染 ----
    // (异步提交到 Metal command queue，不阻塞)
    dispatch_async(dispatch_get_main_queue(), ^{
        [self renderPixelBufferToPreview:pixelBuffer];
        CVPixelBufferRelease(pixelBuffer);
    });

    // ---- 编码路线: VT 编码 ----
    dispatch_async(_encodeQueue, ^{
        [self encodePixelBuffer:pixelBuffer pts:pts];
        CVPixelBufferRelease(pixelBuffer);
    });
}

// MARK: - 第三段-编码: VT 编码

- (void)encodePixelBuffer:(CVPixelBufferRef)pixelBuffer pts:(CMTime)pts {
    if (!_encoderSession) return;

    // 强制关键帧（PLI 触发的）
    CFDictionaryRef frameProps = NULL;
    if (_forceKeyFrame) {
        CFDictionaryRef props = (__bridge CFDictionaryRef)@{
            (__bridge NSString *)kVTEncodeFrameOptionKey_ForceKeyFrame: @YES
        };
        _forceKeyFrame = NO;
        frameProps = props;
    }

    // ★ 编码（异步）→ 结果在 EncoderOutputCallback
    VTCompressionSessionEncodeFrame(
        _encoderSession,
        pixelBuffer,
        pts,
        kCMTimeInvalid,
        frameProps,
        NULL, NULL
    );
}

// ============================================================
// MARK: - 第四段: 编码回调 → 格式转换 → 推流
// ============================================================
static void EncoderOutputCallback(
    void *outputCallbackRefCon,
    void *sourceFrameRefCon,
    OSStatus status,
    VTEncodeInfoFlags infoFlags,
    CMSampleBufferRef sampleBuffer)
{
    if (status != noErr || !sampleBuffer) return;

    RTMPBroadcaster *broadcaster = (__bridge RTMPBroadcaster *)outputCallbackRefCon;

    CFRetain(sampleBuffer);
    dispatch_async(broadcaster->_streamQueue, ^{
        [broadcaster processEncodedFrame:sampleBuffer];
        CFRelease(sampleBuffer);
    });
}

- (void)processEncodedFrame:(CMSampleBufferRef)sampleBuffer {
    // ① AVCC → Annex-B 转换（详见 07-AVCC与Annex-B转换实战.md）
    H264AnnexBPacket *packet = [H264FormatConverter convertToAnnexB:sampleBuffer];

    // ② 推流（简化，实际由 C++ 引擎处理 RTMP 封包）
    [self sendVideoData:packet.data
                    pts:packet.pts
            isKeyFrame:packet.isKeyFrame];

    // ③ 状态统计
    _frameCount++;
    if (_frameCount % 30 == 0) {
        dispatch_async(dispatch_get_main_queue(), ^{
            [self.delegate broadcaster:self
                      didUpdateBitrate:_config.videoBitrate
                                   fps:_config.videoFPS];
        });
    }
}

- (void)startBroadcasting {
    if (_isBroadcasting) return;
    _isBroadcasting = YES;
    _frameCount = 0;

    [self setupCapture];
    [self setupVideoEncoder];
    // [self setupAudio];  // 音频初始化（见 AudioUnit 文档）
    // [self connectRTMP]; // C++ 引擎连接 RTMP 服务器

    dispatch_async(dispatch_get_global_queue(0, 0), ^{
        [_captureSession startRunning];
    });

    [self.delegate broadcaster:self didChangeState:@"推流中"];
}

- (void)stopBroadcasting {
    if (!_isBroadcasting) return;
    _isBroadcasting = NO;

    // ★ 正确的停止顺序:
    // 1. 先停采集（不再有新帧进来）
    [_captureSession stopRunning];

    // 2. Flush 编码管线（把残留帧逼出来）
    if (_encoderSession) {
        VTCompressionSessionCompleteFrames(_encoderSession, kCMTimeInvalid);
    }

    // 3. 等编码回调走完 → 销毁编码器
    dispatch_after(dispatch_time(DISPATCH_TIME_NOW, 0.5 * NSEC_PER_SEC),
                   _encodeQueue, ^{
        if (self->_encoderSession) {
            VTCompressionSessionInvalidate(self->_encoderSession);
            CFRelease(self->_encoderSession);
            self->_encoderSession = NULL;
        }
    });

    // 4. 断开 RTMP 连接
    // engine_->disconnect();

    [self.delegate broadcaster:self didChangeState:@"已停止"];
}

- (void)switchCamera {
    AVCaptureDevicePosition target =
        (_currentCamera.position == AVCaptureDevicePositionBack)
            ? AVCaptureDevicePositionFront
            : AVCaptureDevicePositionBack;

    AVCaptureDevice *newCamera = [self findCamera:target];
    if (!newCamera) return;

    AVCaptureDeviceInput *newInput =
        [AVCaptureDeviceInput deviceInputWithDevice:newCamera error:nil];
    if (!newInput) return;

    [_captureSession beginConfiguration];
    [_captureSession removeInput:_videoInput];
    if ([_captureSession canAddInput:newInput]) {
        [_captureSession addInput:newInput];
        _videoInput = newInput;
        _currentCamera = newCamera;
    } else {
        [_captureSession addInput:_videoInput]; // 回退
    }
    [_captureSession commitConfiguration];
}

- (void)adjustBitrate:(int)newBitrate {
    _config.videoBitrate = newBitrate;
    if (_encoderSession) {
        CFNumberRef br = CFNumberCreate(NULL, kCFNumberIntType, &newBitrate);
        VTSessionSetProperty(_encoderSession,
            kVTCompressionPropertyKey_AverageBitRate, br);
        CFRelease(br);
    }
}

- (void)forceKeyFrame {
    _forceKeyFrame = YES;
}

- (void)setMuted:(BOOL)muted {
    _muted = muted;
    // AudioUnit 的 render callback 里 mute 时填静音
}

@end

│                                                                   │
│  [采集回调线程] captureQueue (串行)                                │
│    ├─ 拿 CVPixelBuffer + PTS                                     │
│    ├─ CVPixelBufferRetain × 2                                    │
│    ├─ dispatch → Metal (主线程)                                   │
│    └─ dispatch → 编码 (encodeQueue)                               │
│                                                                   │
│  [编码线程] encodeQueue (串行)                                     │
│    └─ VTCompressionSessionEncodeFrame → 异步 → 不等待             │
│                                                                   │
│  [编码回调线程] VT 内部线程                                        │
│    └─ ⚡只做: CFRetain → dispatch → streamQueue → 立即返回         │
│                                                                   │
│  [推流线程] streamQueue (串行)                                     │
│    ├─ AVCC → Annex-B 转换                                        │
│    ├─ RTMP 封包                                                  │
│    └─ 网络发送                                                    │
│                                                                   │
│  [主线程]                                                         │
│    └─ Metal draw call + MTKView 刷新                             │
│                                                                   │
│  ★ 关键: 采集回调绝不阻塞、编码回调只做 dispatch                   │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

## 五、关键设计决策

### 5.1 为什么采集回调里做 CVPixelBufferRetain × 2？

因为同一个 IOSurface 要给两条路线用。retain 两次，每个路线处理完各 release 一次。引用计数到 0 后 IOSurface 被回收。如果用 copy，那就破坏了零拷贝优势。

### 5.2 为什么编码回调里不做格式转换？

编码回调跑在 VideoToolbox 的内部线程上。格式转换涉及内存操作（NSMutableData append），不宜在 VT 线程上做。正确做法是 dispatch 到自己的推流队列。

### 5.3 停止的顺序为什么那么重要？

- 先停采集：不再产生新帧，避免"边停边来帧"的竞态
- 再 flush 编码：把硬件管线里排队中的帧逼出来
- 等回调走完：给回调时间处理 flush 出来的帧
- 最后销毁 session

如果顺序反了（先销毁 session 再停采集），编码器正在处理中的帧可能崩溃。

### 5.4 预览帧率和推流帧率的关系

预览 60fps（MTKView 由 CADisplayLink 驱动刷新），推流 30fps。预览侧如果 60fps 但没有新帧到来，保留上一帧的纹理继续渲染——不需要新数据也能显示。推流侧按实际采集帧率走。

## 六、常见坑

### 坑 1：采集和编码速度不匹配

30fps 采集但编码来不及（比如美颜吃性能），会导致编码队列积压、内存暴涨、延时增加。对策：`alwaysDiscardsLateVideoFrames = YES` + 必要时主动降帧率。

### 坑 2：后台处理不当

App 进后台 → AVSession 停止 → 编码器可能失效 → 回前台花屏。对策：监听 `UIApplicationDidEnterBackground` / `WillEnterForeground`，回前台重建 session + 发 SPS/PPS + 强制 IDR。

### 坑 3：强网络抖动时推流断开

RTMP 连接断开时，编码器还在跑、帧还在往队列里塞。对策：连接断时暂停编码（不喂新帧），重连成功后先发 IDR（forceKeyFrame）。

## 🎯 一句话总结

> iOS 端到端推流管线 = AVFoundation 采集（NV12 CVPixelBuffer）+ Metal 零拷贝预览 / VideoToolbox 异步编码（RealTime + 关B帧）+ AVCC→Annex-B 转换（补 SPS/PPS）+ C++ 推流引擎。线程用三级异步 pipeline（采集→编码→发送），共享 CVPixelBuffer 靠 IOSurface 零拷贝，停止时按采集→flush→销毁的顺序。
