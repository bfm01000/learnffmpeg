> 基于你的技术栈（C++ / FFmpeg / Android 硬件零拷贝 / AJB / 异构 Pipeline）与影石 5 年运动相机 SDK 经验整理。每一档都标注了**匹配度**、**典型公司**、**搜索关键词**、**面试侧重**与**给你的话术建议**。

## 一些可以帮你拉高命中率的小动作

1. **简历起标题就用目标公司的岗位名**：投大疆就写"C++ 音视频 / 影像系统工程师"，投车载就写"车载多媒体 / 智能座舱开发"。HR 关键词匹配会更友好。
2. **项目命名前置技术词**：把"Android 4K 全景直播 pipeline 优化"改成"4K 直播零拷贝与 ABR 自适应码率优化"，把"车载相机预览低时延优化"改成"AJB 自适应抖动缓冲调度器设计"——技术词放前面，业务词放后面。
3. **量化数据要狠**：40 ms → 10 ms、1.5 s → 0.5 s、60%+、22 fps → 30 fps、出片速度提升数倍——这些数字一定要保留并放在每条 bullet 的最前面。
4. **GitHub 露出**：你 `learn/` 目录里 100+ 篇技术沉淀可以挑几篇精华整理到 GitHub Pages 或掘金，简历里挂链接。
5. **内推优先于网投**：脉脉 / 即刻 / X / 微信群找内推，命中率比 BOSS / 拉勾高 3 倍以上。
