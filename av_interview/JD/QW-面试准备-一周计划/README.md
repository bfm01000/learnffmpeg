# 千问/夸克 · 浏览器内核岗 · 面试前一周学习计划

> 依据：[QW.md](../QW.md)（JD + 内推说明）  
> 画像：**C++ 特别扎实 · 偏底层 · 不要求浏览器经验**  
> 建议每日投入：**4～5 小时**（工作日 3h 晚上 + 周末可加量）

---

## 一周目标（验收标准）

| 维度 | 第 7 天结束时你应该能…… |
|------|-------------------------|
| C++ | 白板讲清 RAII / 移动语义 / 智能指针 / 虚析构 / 内存序；结合项目里的 `shared_ptr` 跨线程生命周期 |
| 并发 | 手写简化版生产者-消费者；讲透 4K 异步发送队列、自动剪辑三阶段并行、AJB 与锁的关系 |
| 算法 | 累计 **18～21 题**（热题 100 子集），手写无 bug 通过 2 道中等题 |
| 浏览器 | 无辅助画出「多进程 + 渲染管线」架构图；说清 CEF/Electron 解决什么问题 |
| 项目 | 三个项目各有一套 **3 分钟 C++ 向**话术（问题→埋点→方案→数据） |
| 综合 | 完成 1 次 45 分钟自测：自我介绍 + 1 个项目 + 2 道算法 |

## 每日固定动作（每天都做，约 30 分钟）

1. **项目复述**：轮换一个项目，按「问题→埋点→C++方案→量化」说一遍（录音 3 分钟）。
2. **错题/盲点**：把当天卡住的点记到 `周复盘清单.md`。
3. **算法**：Day4 之前可每天 1 题热身；Day4 起按当日计划。
