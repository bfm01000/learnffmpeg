| 快捷键 | 功能 |
|--------|------|
| `cmd-k v` / `ctrl-k v` | 侧边预览 |
| `cmd-shift-v` / `ctrl-shift-v` | 打开预览 |
| `cmd-k shift-l` / `ctrl-k shift-l` | 侧边锁定预览 |
| `cmd-k cmd-shift-l` / `ctrl-k ctrl-shift-l` | 切换预览锁定 |
| `ctrl-shift-s` | 同步预览 / 同步源码 |
| `shift-enter` | 运行代码块 |
| `ctrl-shift-enter` | 运行所有代码块 |
| `cmd-=` / `cmd-shift-=` | 预览放大 |
| `cmd--` / `cmd-shift-_` | 预览缩小 |
| `cmd-0` | 预览重置缩放 |
| `esc` | 切换侧边栏目录 |
